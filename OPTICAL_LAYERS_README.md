# Выборочное использование оптических слоев в Vision Transformer

## Обзор

Добавлена возможность использовать оптические вычисления (или их эмуляцию с шумом) не во всех слоях модели, а только в определенном количестве слоев. Это позволяет создавать гибридные модели, сочетающие оптические и обычные вычисления.

## Новые параметры конфигурации

В файле `config.py` добавлены:

```python
config = {
    # ... существующие параметры ...
    "use_optical": False,            # использовать ли оптическое умножение
    "optical_layers": 0,             # количество слоев с оптикой (0 = все, если use_optical=True)
    "optical_noise_std": 0.0,        # стандартное отклонение шума для эмуляции оптики
}
```

## Примеры использования

### 1. Без оптики (по умолчанию)
```python
config.update({
    "use_optical": False,
})
```

### 2. Оптика во всех слоях
```python
config.update({
    "use_optical": True,
    "optical_layers": 0,  # 0 означает "все слои"
})
```

### 3. Оптика в 4 слоях (равномерное распределение)
```python
config.update({
    "use_optical": True,
    "optical_layers": 4,  # оптика будет в слоях 0, 3, 6, 9 (для 12-слойной модели)
})
```

### 4. Оптика с шумом
```python
config.update({
    "use_optical": True,
    "optical_layers": 4,
    "optical_noise_std": 0.1,  # добавляет шум к оптическим вычислениям
})
```

## Как это работает

### Распределение оптических слоев

При `optical_layers = N` (где N > 0):
- Оптические вычисления используются в N слоях
- Слои распределяются равномерно по архитектуре
- Например, для 12-слойной модели:
  - `optical_layers=1`: слой 0
  - `optical_layers=4`: слои 0, 3, 6, 9
  - `optical_layers=6`: слои 0, 2, 4, 6, 8, 10

При `optical_layers = 0`:
- Если `use_optical=True`, оптика используется во всех слоях
- Если `use_optical=False`, оптика не используется ни в одном слое

### Эмуляция шума

Параметр `optical_noise_std` добавляет гауссовский шум к результатам оптических вычислений:
- `optical_noise_std=0.0`: без шума (по умолчанию)
- `optical_noise_std=0.1`: добавляет шум со стандартным отклонением 10% от значения

## Архитектурные изменения

### 1. Функция `optics_matmul` (model.py)
- Добавлен параметр `noise_std` для контроля уровня шума
- Улучшена обработка устройств (CPU/GPU)

### 2. Класс `AttentionHead` (model.py)
- Добавлен параметр `noise_std`
- Передает параметр шума в `optics_matmul`

### 3. Класс `MultiHeadAttention` (model.py)
- Добавлены параметры `layer_idx` и `total_layers`
- Добавлена логика определения `layer_use_optical` на основе `optical_layers`
- Равномерно распределяет оптические слои по архитектуре

### 4. Класс `Block` (model.py)
- Передает `layer_idx` и `total_layers` в `MultiHeadAttention`

### 5. Класс `Encoder` (model.py)
- Передает индекс слоя при создании каждого `Block`

## Преимущества

1. **Гибкость**: Можно экспериментировать с разным количеством оптических слоев
2. **Эффективность**: Можно использовать оптику только в критически важных слоях
3. **Исследования**: Позволяет изучать влияние оптических вычислений на разных этапах обработки
4. **Робастность**: Шумовая эмуляция помогает изучать устойчивость к неточностям оптических вычислений

## Использование в исследованиях

Новая функциональность позволяет исследовать:
- Оптимальное количество оптических слоев для конкретной задачи
- Влияние шума оптических вычислений на точность модели
- Комбинации оптических и обычных вычислений в гибридных архитектурах
- Распределение оптических слоев по глубине сети
